# 依頼内容（原文）

現在ログインをすると初期画面のヘッダーに「名前さん」という表記が出ていて何も押せない状態になっています。こちらは不要なので消していただき、その下にある「今日は何をしますか」という文言の前に「〇〇さん、今日は何をしますか」という形に変更をお願いします。

# 要点整理
- ログイン後の初期画面ヘッダーに「名前さん」という表記が出ている（クリック等の操作ができない状態＝おそらくプレースホルダー文言がそのまま表示されている不具合）
- この「名前さん」表記を削除する
- 現在ヘッダー下部にある「今日は何をしますか」という文言の前に、実際のユーザー名（例: 〇〇さん）を付与し「〇〇さん、今日は何をしますか」という形にする
