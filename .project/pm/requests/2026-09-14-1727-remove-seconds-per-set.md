# 依頼内容

## ユーザーの依頼（原文）
> 1セットあたり秒数（任意）は不要なので削除してください

## 背景
- `src/components/WorkoutLogForm.tsx` にある「1セットあたり秒数（任意）」入力欄と「セット数×秒数から時間を計算」ボタンは、
  運動時間（分）を自動計算するための**クライアント側のみの補助UI**（DBには保存されず、`secondsPerSetOverride`等のフィールドはPrismaスキーマ・Server Action・DTOのいずれにも存在しない）。
- 初回調査で `secondsPerSetOverride` という語はコンポーネント内にも見当たらず、単なる入力欄名・ローカルstateとして実装されている可能性が高い。正確な実装は設計フェーズで確認する。

## 成功条件
- 記録追加・編集フォームから「1セットあたり秒数（任意）」入力欄と「セット数×秒数から時間を計算」ボタンが削除される。
- 「運動時間（分）」欄は引き続きユーザーが直接入力できる（削除対象はあくまで秒数からの自動計算補助UIのみ）。
- 既存の記録データ・カロリー計算には一切影響がない（このUIはDBに保存されない値のため）。
- 既存テストが通ること。関連するE2Eテストがあれば更新する。
