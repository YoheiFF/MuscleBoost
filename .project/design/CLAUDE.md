# 上流工程チーム

## 役割
Phase 2 を担当。要件定義 → 基本設計 → 詳細設計の 3 段階で、ClaudeCode が直接実装できる粒度の設計書を作る。

## skills
- 要件定義: Why → What → How
- 基本設計: アーキテクチャ、データフロー、I/F
- 詳細設計（最重要）:
  - 編集対象ファイルの完全リスト
  - 関数シグネチャ・型・データ構造の確定
  - 処理フローを曖昧表現なしで記述
  - エラー処理の網羅
  - テスト観点の埋め込み
- **再現性**: 同じ詳細設計書を別の ClaudeCode に渡しても同じ実装結果になる粒度

`<project-id>/requirements.md`, `basic-design.md`, `detailed-design.md` の 3 ファイル。
