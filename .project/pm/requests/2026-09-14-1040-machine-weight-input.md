# 依頼内容

## ユーザーの依頼（原文）
> 今マシンのプルダウンには同じマシーンでもいくつかのレベルに分かれて数種類の選択肢になっているのはなぜ？
> 選択しとしては1つにし、別項目にて重さ(KGやポンド)の記入欄を作成できますか？

## 背景
- 既存実装（プロジェクト `2026-09-12-1539-gym-tracker`）では、マシンマスタ（Exercise）を「マシン名 × 強度レベル（軽度/中等度/高強度）」の組み合わせで保持しており、
  同じマシンでも複数の選択肢がプルダウンに表示される仕様だった（MET値がマシン単位ではなく運動強度単位でしか公的に定義されていないため）。
- ユーザーはこれを1マシン=1選択肢に統一し、代わりに新規に「重さ」の入力欄（KG/ポンド切り替え可能）を追加したいと要望。

## 確認済みのスコープ（AskUserQuestionで確認済み）
- 「重さ」の入力値はカロリー計算には使わない。**記録用（保存・表示）のみ**。
- カロリー計算式・MET値ベースのロジックは変更しない。
- マシンごとのMET値は「1マシン=1つ」に統一する必要がある（強度レベルのバリエーションをどう1つにまとめるか＝設計判断が必要。デフォルトは中等度を基準にする想定だが、設計フェーズで確定させる）。

## 成功条件
- マシン選択プルダウンに同一マシン名が複数出ない（1マシン1エントリ）。
- トレーニング記録フォームに「重さ」入力欄（数値）と単位（KG/ポンド）の選択が追加され、DBに保存・記録一覧に表示される。
- 既存のカロリー計算ロジック・過去記録のMET値スナップショットの仕組みに悪影響を与えない。
- 既存のテスト（Vitest/Playwright）が通ること、および新規追加分のテストも通ること。
