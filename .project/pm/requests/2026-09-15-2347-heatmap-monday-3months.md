# 依頼内容（原文）

トレーニングカレンダーは上から順に月曜から金曜になっている？
→ 実際は月曜始まりに整列しておらず、単純な7日チャンクだった（本日の曜日により先頭行が変動する）ことをPMが回答。

上から順に月曜日から金曜日で固定にして、過去二か月分までを含めた状態で表示されるように修正する事は可能ですか
→ ユーザーへの確認の結果、以下の通り確定:
- 「月曜日から金曜日」は「月曜始まりの1週間（月〜日の7行）」の意味（曜日の範囲を金曜までに絞る=平日のみ表示、ではない）
- 表示期間は「当月も含めて過去2か月、合計3か月分が見えている状態」にしたい（現状は直近1年=371日）

# 要点整理
1. カレンダーヒートマップ（src/components/WorkoutHeatmap.tsx, src/lib/achievements.ts の buildWorkoutHeatmap）の週の区切り方を、単純な「今日から371日前を起点とした7日チャンク」から「暦週（月曜始まり、月〜日の7行）」に整列する方式へ変更する
2. 表示期間を、直近1年（371日）から「当月＋過去2ヶ月＝合計3ヶ月分」に変更する
3. ストリーク（連続日数）等の既存の集計ロジックは、表示期間の変更後も正しく動作する必要がある（ロジック自体は表示ウィンドウと分離されているか要確認）
