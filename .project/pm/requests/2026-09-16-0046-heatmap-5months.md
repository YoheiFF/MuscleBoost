# 依頼内容（原文）

スマホで見た際に途切れていた、、5か月にしてリリースまでお願いします、

# 背景
直前の対応（2026-09-16-0032-heatmap-6months）で表示期間を「当月＋過去5ヶ月＝6ヶ月分」に
変更したところ、スマホ幅で表示が途切れる（グリッド幅が画面に収まらない）とのフィードバック。
ユーザー指定により表示期間を「当月＋過去4ヶ月＝合計5ヶ月分」に縮小し、本番反映まで対応する。

グリッド自体は`overflow-x-auto`で横スクロール可能な実装だが、月数を1つ減らすことで
グリッド幅自体を縮小し、スマホ幅での視認性を改善する対応とした。
